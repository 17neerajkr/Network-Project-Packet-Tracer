# 🌐 Network Project – Cisco Packet Tracer

A practical **Computer Networking project** designed and simulated using **Cisco Packet Tracer**. The project demonstrates network topology design, IP addressing, routing, switching, connectivity testing, and network troubleshooting.

## 📌 Project Overview

This project was developed to understand and implement fundamental networking concepts in a simulated environment.

The network includes multiple network devices and end systems configured to communicate with each other using standard networking protocols and configurations.

## 🎯 Objectives

- Design a functional computer network topology.
- Configure routers and switches.
- Implement IPv4 addressing and subnetting.
- Configure routing between different network segments.
- Understand TCP/IP-based communication.
- Test network connectivity between devices.
- Identify and troubleshoot basic network configuration issues.
- Improve practical understanding of network administration.

## ⚙️ Key Configurations

### IP Addressing

Configured IPv4 addresses for network devices and end systems to establish communication between different network segments.

### Routing

Configured routing between networks to allow devices connected to different segments to communicate.

### Switching

Configured switches to provide connectivity between end devices within the local network.
